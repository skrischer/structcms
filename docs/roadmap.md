## Current focus
**Phase 1: Draft/Publish States**

Introduce draft vs. published content states, a publish workflow, and preview
endpoints so editors can stage changes before they go live — the first capability
beyond the shipped MVP and the foundation localization and multisite build on.

## North star
A code-first headless CMS that grows from typed content modeling to staged,
localized, multi-site delivery without ever leaving the host repository or
sacrificing type safety.
